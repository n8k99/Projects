# Projects

100+ programming projects implemented as modular libraries in six languages.

A Rosetta Stone — not for syntax comparison, but for paradigm comparison.

## Languages

| Language | Paradigm | Purpose |
|----------|----------|---------|
| Common Lisp | Functional / multi-paradigm | The ancestor |
| Python | Imperative / multi-paradigm | The baseline |
| Rust | Systems / ownership | The discipline |
| Go | Concurrent / imperative | The pragmatist |
| Lean | Dependent types / proofs | The verifier |
| InnateScript | Choreographic / markdown-native | The experiment |

## Categories

Each category is a modular library in each language.

| Category | Projects | Focus |
|----------|----------|-------|
| numbers | 15 | Math, algorithms, converters |
| text | 17 | String processing, encryption, generators |
| networking | 15 | Protocols, servers, scanners |
| classes | 17 | OOP, data structures, simulation |
| threading | 4 | Concurrency, parallelism |
| web | 16 | Browsers, CMS, automation |
| files | 16 | I/O, compression, management |
| databases | 13 | SQL, CRUD, reporting |
| graphics | 17 | Media, image processing, visualization |

## Structure

```
projects/
  <language>/
    <category>/
      README.md          — category overview, module API
      <project>.ext      — one file per project as a library module
```

## Approach

One problem per night. All six languages. The libraries grow together.

The InnateScript versions are design feedback — if the language can't express a problem, that's a gap in the spec.

## Origin

Forked from [n8k99/projects](https://github.com/n8k99/projects). Original concept: 100 projects to learn a language. This version: 100 projects to compare six paradigms and stress-test a language being designed.
